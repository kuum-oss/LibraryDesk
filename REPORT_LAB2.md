# Звіт з лабораторної роботи №2 (Завдання 7)

## Вимкнені правила StyleCop

В ході виконання завдання було підключено `StyleCop.Analyzers` та налаштовано `.editorconfig`. Деякі правила були вимкнені або переведені у статус `none` з наступних причин:

1. **SA1633 (File should have header)**: Вимкнено (`none`), оскільки це навчальний проєкт, і додавання ліцензійних заголовків до кожного файлу є надлишковим.
2. **SA1200 (Using directives should be placed correctly)**: Вимкнено (`none`), оскільки правило вимагає розміщення `using` всередині `namespace`, що суперечить сучасному стандарту C# (file-scoped namespaces) та налаштуванням нашого курсу.
3. **SA1101 (Prefix local calls with this)**: Вимкнено (`none`), оскільки використання префікса `this.` для членів класу не є прийнятою практикою в межах даного курсу та робить код менш лаконічним.
4. **SA1309 (Field names should not begin with underscore)**: Вимкнено (`none`), оскільки це суперечить загальноприйнятій конвенції .NET та налаштуванням нашого проєкту, де приватні поля повинні починатися з символу підкреслення (`_`).

## Залишені та виправлені правила

1. **SA1503 (Braces should not be omitted)**: Залишено як `warning` (фактично `error` через жорсткий режим). Це правило курсу, яке вимагає обов'язкових фігурних дужок навіть для однорядкових блоків. Виправлено за допомогою `dotnet format`.
2. **SA1600 (Elements should be documented)**: Залишено як `warning`. Усі публічні класи та їх члени були задокументовані за допомогою XML-коментарів (`summary`).
3. **CS1591 (Missing XML comment for publicly visible type or member)**: Увімкнено для забезпечення повної документації публічного API.

## Верифікація

- Збірка проєкту виконується успішно з параметром `TreatWarningsAsErrors=true`.
- Команда `dotnet format --verify-no-changes` не повертає помилок.
- Порівняння виводу програми (`diff docs/lab02/before.txt docs/lab02/after.txt`) підтвердило, що поведінка коду не змінилася.
