### 3. Хід виконання роботи

#### 3.1. Завдання 1. Підключення StyleCop.Analyzers та конфігурація MSBuild
У корені рішення у файлі `Directory.Build.props` було централізовано налаштовано параметри збірки. Пакет `StyleCop.Analyzers` підключено безпосередньо у файли проектів `.csproj`. Встановлено наступні властивості:
- `TreatWarningsAsErrors=true` — трактування всіх попереджень як помилок.
- `EnforceCodeStyleInBuild=true` — перевірка стилю коду під час компіляції.
- `GenerateDocumentationFile=true` — примусова генерація XML-документації.

#### 3.2. Завдання 2. Налаштування файлу .editorconfig та аналіз правил StyleCop
Було налаштовано `.editorconfig`. Деякі правила вимкнено (none):
- **SA1633**: Вимкнено, оскільки це навчальний проєкт.
- **SA1200**: Вимкнено через використання file-scoped namespaces.
- **SA1101**: Вимкнено, оскільки `this.` не є обов'язковим у курсі.
- **SA1309**: Вимкнено для підтримки конвенції `_` для приватних полів.

#### 3.3. Завдання 3. Рефакторинг та форматування коду
Використано `dotnet format` для приведення коду до стандарту: додано фігурні дужки, виправлено відступи, впорядковано `using`.

#### 3.4. Завдання 4. Повне XML-документування публічного API
Усі публічні типи та члени у `LibraryDesk.Core` задокументовані XML-тегами. Це усунуло попередження CS1591 та SA1600.

#### 3.5. Завдання 5. Верифікація поведінки програми
Порівняно виводи: `diff docs/lab02/before.txt docs/lab02/after.txt`. Команда не виявила розбіжностей, що підтвердило безпечність рефакторингу.

#### 3.6. Лістинги вихідного коду (фрагменти)

**Лістинг 1 — .editorconfig (фрагмент вимкнених правил)**
```ini
# Вимкнені правила StyleCop (none)
dotnet_diagnostic.SA1633.severity = none
dotnet_diagnostic.SA1200.severity = none
dotnet_diagnostic.SA1101.severity = none
dotnet_diagnostic.SA1309.severity = none
```

**Лістинг 2 — LibraryDesk.Core/Domain/Loan.cs**
```csharp
namespace LibraryDesk.Core.Domain;

/// <summary>Формуляр видачі книг читачеві.</summary>
public sealed class Loan
{
    private readonly List<LoanItem> _items = new();
    // ... інші члени ...
    /// <summary>Обчислює загальну вартість прокату книг у формулярі.</summary>
    public decimal Total()
    {
        decimal sum = 0m;
        foreach (LoanItem item in _items)
        {
            sum += item.Amount;
        }
        return sum;
    }
}
```

### 6. Відповіді на контрольні питання
1. **Статичний аналіз коду** — це автоматизована перевірка коду без його запуску для виявлення помилок та порушень стилю.
2. **Roslyn (CA)** фокусується на логіці та безпеці, **StyleCop (SA)** — на стилі оформлення.
3. **TreatWarningsAsErrors** робить неможливою збірку проекту з попередженнями, що підвищує якість коду.
4. **diff before.txt after.txt** гарантує, що рефакторинг не змінив логіку роботи програми.
