# Завдання 3 Параметризовані тести та винятки

Шість однотипних перевірок таблиці меж об'єднано в одну теорію
`Calculate_Boundaries_MatchesTable`. Значення грошей передаються до
`InlineData` як `double`, а в тілі тесту явно перетворюються на `decimal`,
оскільки атрибут не приймає `decimal` як константу часу компіляції.

Окрема теорія перевіряє два представники некоректного класу: -1 і -30
днів. `Assert.Throws` не лише підтверджує точний тип винятку, а й повертає
його об'єкт; завдяки цьому тест додатково перевіряє `ParamName` зі значенням
`overdueDays`.
