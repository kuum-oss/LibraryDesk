# Завдання 1 Проєкт модульних тестів

Робота продовжує наявне рішення `LibraryDesk.sln`. Проєкт
`LibraryDesk.Tests` уже був створений у попередніх лабораторних роботах і має
односпрямоване посилання на `LibraryDesk.Core`, тому дублювати тестовий проєкт
не потрібно. Для ЛР 7 до нього додано `coverlet.collector`, потрібний у
завданні 6 для збору покриття.

Перевірені інструменти:

- .NET SDK 10.0.103, що відповідає вимозі версії 8 або новішої;
- Git 2.54.0;
- xUnit у відокремленому проєкті `LibraryDesk.Tests`;
- початковий запуск рішення: 26 тестів, усі пройшли.

Тести винесено з доменного проєкту, щоб продуктивний код не залежав від xUnit,
тестового SDK та засобів покриття. Напрям залежності залишається правильним:
`LibraryDesk.Tests` залежить від `LibraryDesk.Core`, але не навпаки.
