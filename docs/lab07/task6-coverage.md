# Завдання 6 Покриття тестами

Через накопичені модулі попередніх лабораторних робіт повне
`LibraryDesk.Core` має багато коду поза обсягом ЛР 7. Файл
`lab07.runsettings` чесно обмежує вимірювання двома класами цієї роботи:
`LateFeePolicy` і `LoanService`. Команда вимірювання в обох запусках однакова:

```text
dotnet test LibraryDesk.Tests/LibraryDesk.Tests.csproj \
  --settings docs/lab07/lab07.runsettings \
  --collect:"XPlat Code Coverage"
```

| Показник | До нових тестів | Після нових тестів | Зміна |
|---|---:|---:|---:|
| Покриття рядків | 63,15% (60/95) | 98,94% (94/95) | +35,79 п.п. |
| Покриття гілок | 59,09% (13/22) | 81,81% (18/22) | +22,72 п.п. |

| Гілка або умова | Клас | Стан і причина | Дія |
|---|---|---|---|
| `loan.Status != Active` | `LoanService` | була непокрита | додано тест чернетки |
| `loan.ReaderId != reader.Id` | `LoanService` | була непокрита | додано тест іншого читача |
| `total == 0` | `LoanService` | була непокрита | додано тест нульової ціни |
| `repository.Add` кидає `IOException` | `LoanService` | була непокрита | додано дублер зі збоєм |
| `total < 0` | `LoanService` | була непокрита | додано тест від'ємної ціни |
| `repository is null` | конструктор `LoanService` | тест не написано | залишено як тривіальний guard |
| `pricing is null` | конструктор `LoanService` | тест не написано | залишено як тривіальний guard |
| `notifier is null` | конструктор `LoanService` | тест не написано | залишено як тривіальний guard |
| `logger is null` | конструктор `LoanService` | тест не написано | залишено як тривіальний guard |

Один непокритий рядок `LateFeePolicy` відповідає десятковій константі, яку
компілятор вбудовує в код; це не окрема поведінкова гілка. HTML-звіт
ReportGenerator створено з фінального `coverage.cobertura.xml` і перевірено.

Покриття не доводить відсутності дефектів: воно показує факт виконання
рядків і переходів, але не якість тверджень `Assert` та не повноту вибраних
вхідних класів. Саме тому результат доповнено межовими тестами, перевіркою
винятків і контрольованою мутацією умови.
