# Журнал рішень стандарту

## ADR-001 · 2026-10-06 · Напіввідкритий строк видачі

**Рішення:** `DueDateExclusive` — перший день прострочення; перевірка `today >= DueDateExclusive`.

**Причина:** календарний строк не залежить від часу доби. Альтернатива «останній дозволений день» породжує помилки `>`/`>=`.

**Наслідок:** `DateOnly`, суфікс `Exclusive` і граничні тести.

## ADR-002 · 2026-10-06 · Приватні поля з `_`

**Рішення:** instance-поля `_camelCase`, static-поля `s_camelCase`; `SA1309` вимкнено.

**Причина:** префікс відрізняє стан об’єкта від параметра й не вимагає `this.`. Це відповідає dotnet/runtime, але суперечить дефолтному StyleCop.

**Наслідок:** naming rule і suppression із поясненням у `.editorconfig`.
