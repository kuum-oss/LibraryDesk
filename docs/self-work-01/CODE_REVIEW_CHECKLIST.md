# Чекліст code review LibraryDesk

- [ ] Назви відповідають термінам LibraryDesk.
- [ ] Зміна робить одну предметну річ.
- [ ] Гроші мають `decimal`, а округлення виконується один раз.
- [ ] `DueDateExclusive` однозначно задає перший день прострочення.
- [ ] Прострочення перевіряється на переданій даті, без системного годинника.
- [ ] Невалідний строк видачі відхиляється, а не стає нулем.
- [ ] Немає проковтнутих винятків і порожніх `catch`.
- [ ] Кожна нова гілка логіки має позитивний і негативний тест.
- [ ] Перевірено перший і останній день напіввідкритого інтервалу.
- [ ] Public колекція не дозволяє змінити внутрішній список.
- [ ] Побічні ефекти очевидні з назви та документації.
- [ ] Новий public API має приклад використання.
- [ ] Немає закоментованого коду й TODO без номера задачі.
- [ ] Зауваження містить конкретну дію, а не оцінку.
- [ ] Зауваження адресоване коду, а не автору.
- [ ] PR містить `dotnet build -warnaserror`.
- [ ] Немає зайвих змін поза межами задачі.
