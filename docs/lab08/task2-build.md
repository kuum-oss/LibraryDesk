# Завдання 2. Складання та версіювання

Спільні властивості всіх проєктів винесено до `Directory.Build.props`:
цільова платформа .NET 8, nullable-контекст, неявні `using`, C# 12, сувора
обробка попереджень, аналізатори, перевірка стилю та версія `0.8.0`.

| Конфігурація | Розмір Core.dll | Час складання | Оптимізація |
|---|---:|---:|---|
| Debug | 46 592 байти | 7,33 с | вимкнена |
| Release | 44 544 байти | 3,35 с | увімкнена |

Перший рядок консольного застосунку після складання Release:

```text
LibraryDesk v0.8.0
```

`VersionInfo` читає `AssemblyInformationalVersionAttribute` і відкидає
метадані після символу `+`, тому застосунок показує саме семантичну версію.
