# Завдання 3. Форматування та статичний аналіз

`StyleCop.Analyzers 1.2.0-beta.556` уже був підключений до `LibraryDesk.Core`
і `LibraryDesk.App`. Правило CA1305 переведено з `none` у `warning`, тому
неявна залежність від поточної культури тепер зупиняє сувору збірку.

## Усунені діагностики

| Код | Файл | Суть зауваження | Як усунено |
|---|---|---|---|
| CS0219 | Reports/ReportBuilder.cs | невикористана змінна `notUsed` | змінну видалено |
| CA1051, SA1401 | Reports/ReportBuilder.cs | публічне змінюване поле `Title` | замінено на властивість `init` |
| CA1304, CA1311 | Reports/ReportBuilder.cs | `ToUpper()` залежить від культури | використано `ToUpperInvariant()` |
| CA1305 | Order.cs | `ToString` і `Parse` без культури | передано `CultureInfo.InvariantCulture` |
| CA1305 | src/Legacy/ReportBuilder.cs | формат грошей залежить від культури | передано `CultureInfo.InvariantCulture` |

## Пояснення вимкнених правил

- SA0001 — службова діагностика XML-документації не дає корисного сигналу для цього рішення.
- SA1101 — обов'язковий `this.` суперечить прийнятій сучасній конвенції .NET.
- SA1200 — `using` поза простором імен відповідають шаблонам сучасного C#.
- SA1204 — порядок статичних членів визначається логікою класу, а не універсальним правилом.
- SA1309 — приватні поля навмисно мають префікс `_`.
- SA1413 — кінцева кома в багаторядковому ініціалізаторі не є обов'язковою.
- SA1601 — partial-елементи не потребують дублювання документації.
- SA1623, SA1642 — англомовні шаблони XML не застосовуються до україномовних описів.
- SA1633 — ліцензійний заголовок не потрібний у навчальному репозиторії.

Контрольні команди `dotnet build -c Release` і
`dotnet format --verify-no-changes --no-restore` завершилися з кодом 0.
