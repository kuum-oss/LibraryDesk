# Завдання 6. Чекліст безпечного коду

Зовнішній рядок формату `ISBN;дні;денний тариф` тепер проходить через
`LoanItemParser.TryParse`. Парсер перевіряє кількість полів, довжину ISBN,
діапазон днів 1–365, тариф 0–100 000 і використовує інваріантну культуру.

| № | Пункт | Як перевірено | Результат |
|---:|---|---|---|
| 1 | Ввід не потрапляє в `Parse` без перевірки | `LoanItemParser.TryParse` | небезпечний шлях замінено |
| 2 | Перевірено формат, межі чисел і довжину ISBN | 9 невалідних рядків у `Theory` | так |
| 3 | Секретів у коді немає | `git grep` | збігів немає |
| 4 | Секретів в історії немає | `git log -S "ApiKey" --all` | збігів немає |
| 5 | Локальні налаштування ігноруються | `.gitignore` | додано `.env*`, local settings і secrets JSON |
| 6 | Вразливих пакетів немає, аудит вбудовано | `dotnet list package --vulnerable`, `NuGetAuditMode=all` | 0 пакетів, аудит увімкнено |

Команда `--outdated` окремо показала доступні нові версії, але вона не є
аудитом безпеки: на відміну від `--vulnerable`, вона порівнює номери версій,
а не базу відомих уразливостей.

Після зміни виконано 66 тестів рішення: 54 основних і 12 успадкованих.
Покриття `LibraryDesk.Core` становить 68,62% рядків і 61,73% гілок.
