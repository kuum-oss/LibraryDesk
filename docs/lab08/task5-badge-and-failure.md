# Завдання 5. Бейдж і демонстрація зламаної збірки

README містить бейдж workflow `CI`, який веде на сторінку запусків:

`https://github.com/kuum-oss/LibraryDesk/actions/workflows/ci.yml`

## Порівняння запусків

| Запуск | Коміт | Стан | Тривалість | Результат |
|---|---|---|---:|---|
| CI #2 | `3c1ef0c` | Failure | 40 с | CS0168, exit code 1 |
| CI #3 | `f07e57e` | Success | 45 с | усі quality gates пройдено |

Червоний коміт додав невикористану локальну змінну `qualityGateProbe`.
Через `TreatWarningsAsErrors` попередження CS0168 стало помилкою та зупинило
Release-збірку. Наступний окремий коміт видалив змінну; після повної локальної
перевірки серверний конвеєр знову став зеленим.

Правило «зламана збірка — найвищий пріоритет» захищає спільну гілку:
доки базова перевірка червона, неможливо відрізнити новий дефект від уже
наявного, а кожен наступний коміт збільшує вартість пошуку причини.
