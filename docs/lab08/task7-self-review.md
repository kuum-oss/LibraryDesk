# Завдання 7. Самоогляд перед pull request

Під час перегляду різниці `main...feature/ci-pipeline` знайдено й виправлено:

1. Посилання README містили абсолютний шлях локального Mac. Їх замінено
   на переносні відносні посилання репозиторію.
2. `LoanItemParser` нормалізував перший елемент до окремої перевірки
   кількості полів. Перевірку `parts.Length` перенесено перед доступом до поля.
3. Завдання GitHub Actions не мало верхньої межі часу. Додано
   `timeout-minutes: 10`, щоб завислий процес не витрачав хвилини безмежно.

Шаблон `.github/pull_request_template.md` містить опис, команди перевірки та
заповнений чекліст самоогляду. Створення й злиття PR виконується лише після
публікації гілки та зеленого серверного запуску.
