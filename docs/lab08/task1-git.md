# Завдання 1. Порядок у Git

- Робоча гілка: `feature/ci-pipeline`.
- Початкова точка: актуальний `main` (`c5ca98c`).
- Повідомлення комітів оформлюються за Conventional Commits.
- Кожне завдання лабораторної роботи фіксується окремим тематичним комітом.
- Перевірка `git ls-files` підтвердила, що каталоги `bin`, `obj`, `.vs` та `.idea`
  не відстежуються.

Команда перевірки:

```bash
git ls-files | rg '(^|/)(bin|obj|\.vs|\.idea)/'
```

Порожній результат означає, що артефакти складання та локальні каталоги IDE
не потрапляють до історії репозиторію.
